# Frontend Mentor - Skilled e-learning landing page

Solution to the Skilled e-learning landing page challenge on [Frontend Mentor](https://www.frontendmentor.io).

![Design preview](./preview.jpg)

## Features

- Responsive landing page: hero with call to action, course category cards (animation, design, photography, crypto, business) and footer
- Mobile, tablet and desktop layouts
- Design tokens (colors and Plus Jakarta Sans) defined in the Tailwind config

## Stack

HTML, Tailwind CSS v3.

## Running

```bash
npm install
npm run dev:tw    # watch-builds the CSS into dist/output.css
```

Then open `index.html` in the browser.
